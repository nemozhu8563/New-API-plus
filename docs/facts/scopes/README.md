# 范围事实

本目录用于单仓多项目、多服务或多技术栈项目。普通单项目可以只保留本说明文件。

范围文件记录某个稳定范围如何承载全局事实。它不是另一套全局规则，也不按一次性变更拆分。

## 命名

使用稳定范围名创建文件：

```text
docs/facts/scopes/<范围名>.md
```

当前项目已确认的稳定范围：

```text
docs/facts/scopes/backend.md
docs/facts/scopes/relaykit.md
docs/facts/scopes/frontend.md
```

新增范围必须先由项目证据确认，并在 `docs/facts/current-system.md` 的范围映射中登记。
