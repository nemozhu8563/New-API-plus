デジタルサービスは提供または消費されると通常回復できません。適用法が別途求める場合を除き、返金は次によります。

- 規約違反、認証情報漏えい、誤操作、過剰利用、詐欺または悪意あるチャージバックによる料金は通常返金されません。
- 地域要件、リスク管理、上流ポリシーまたは決済サービスの規則により継続利用できない場合、消費済み、提供済みおよび付与分は通常返金されません。未使用かつ未提供の実支払分は本条により審査申請できます。第3条違反または地域制限回避の場合、適用法の許す範囲で返金を拒否できます。
- 承認された返金は原則として元の支払方法に戻され、着金時期は Stripe、銀行、カードネットワークおよび支払方法によります。

承認された返金またはチャージバック等の紛争により資金損失が生じた場合、付与済みのクォータ・権益はその割合に応じて自動的に回収されます。回収しても不足する額は未払残高となり、その後のチャージはまず未払残高の返済に充当されます。完済されるまで Relay API は停止されますが、アカウントおよびウォレットには引き続きアクセスできます。

Stripe がすべての返金に一律の固定割合の手数料を課すわけではありません。決済サービス提供者は元取引の処理手数料を返還しない場合があり、支払方法、通貨、換算またはアカウント料金に応じた費用を課す場合があります。重複請求、誤請求、当社が未提供と確認した場合その他当社が責任を負うべき場合以外で、お客様が任意に求める返金について、LOOPLEAP LLC は返金可能額の **5%** を返金処理費として請求します。これは Tryvalo の手数料であり、Stripe が一律に定めまたは徴収する返金手数料ではありません。

任意返金の計算は **見込返金純額 = 返金可能額 × 95%** です。返金可能額は未使用・未提供の実支払分のみで計算し、使用済み、提供済みおよび付与権益は基礎に含めません。二重請求、誤請求、当社が未提供と確認した場合、その他当社が責任を負う場合、または適用法が全額返金を求める場合は5%の処理費を課しません。

返金実行前に、元注文の実支払額、使用・提供済み分、返金可能額、処理費および見込返金純額を説明します。

返金申請は [contract@tryvalo.com](mailto:contract@tryvalo.com) にアカウントメール、注文番号、理由および必要な証明を添えて送ってください。Tryvalo は通常1営業日以内に受領を確認し、資料が揃ってから3～5営業日以内に審査結果を出します。追加資料、決済サービス提供者の調査またはチャージバック紛争が必要な場合は延長され、進捗を通知します。承認後は通常2営業日以内に元の支払方法へ返金を開始します。最終的な着金は Stripe、銀行、カードネットワークおよび方法によります。いかなる条項も、適用法上の強行的な消費者権利を制限しません。
