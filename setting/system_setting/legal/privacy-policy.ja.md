## 1. 収集する情報

利用する機能に応じ、次の情報を取り扱う場合があります。

- **アカウント・本人確認情報**：ユーザー名、表示名、メールアドレス、アバター、アカウント識別子、ログイン方法、第三者 OAuth 識別子、アカウント役割、状態、設定および認証状態。
- **認証情報・セッション情報**：パスワードの安全な処理記録、ログインセッション識別子、アクセストークン、API Key の必要な記録、認証バージョンおよびアカウントのセキュリティ状態。
- **請求・取引情報**：チャージまたはサブスクリプション、注文番号、金額、通貨、支払状況、返金・紛争記録、Stripe Customer ID その他必要な決済事業者の取引識別子。完全なカード番号、銀行口座認証情報およびセキュリティコードは通常 Stripe 等が直接処理し、当社は Tryvalo サーバーに完全なカード番号を保存しません。
- **利用・課金メタデータ**：選択モデル・機能、API Key 識別子または名称、リクエスト時刻・状態、リクエスト ID、上流リクエスト ID、Token 数、クォータ消費、残高変動、プラン権益、レート・同時実行制限、応答時間、エラーおよびサービス品質指標。
- **技術・端末データ**：IP アドレス、IP または請求情報から推定される地域、User-Agent、ブラウザ・端末種別、OS、アクセス時刻、参照元、Cookie、ローカルストレージ、セッション識別子その他類似技術のデータ。
- **リスク管理・セキュリティ情報**：異常なログイン・呼出し、地域制限判定、決済・チャージバックリスク、詐欺・濫用シグナル、API Key 漏えいリスク、アクセス制御結果およびセキュリティ事象の記録。
- **サポート・チケット情報**：相談、フィードバック、返金、請求紛争またはトラブルシューティングで提出された文章、連絡先、スクリーンショット、ファイル、リクエスト・出力例および通信記録。
- **規約・リクエスト記録**：サービス契約または本ポリシーへの同意、登録、ログイン、支払い、返金、アカウント変更および権利請求に関する必要な監査記録。

## 2. Prompt、Completion とユーザーコンテンツ

Tryvalo は原則として、完全なユーザー Prompt、Completion、コード片、ファイル内容または生成内容を長期的な業務記録として保存しません。通常の利用・課金記録には主にモデル、Token、クォータ、時刻、状態、リクエスト識別子、エラーおよび性能等のメタデータを保存します。

API またはモデルリクエストを実行するため、当社は関連する Prompt、ファイル、パラメータその他ユーザーコンテンツを受領・解析し、お客様が選択した、またはシステムがルーティングした第三者 AI/API サービス提供者へ送信し、返された Completion または結果を処理します。完全な内容は、リクエスト転送、メモリ処理、一時キャッシュ、セキュリティチェック、障害調査、デバッグ、非同期タスク、特定の履歴機能、上流処理または法的要請のため一時的に処理または限定保存されることがあります。状況は機能、システム設定、上流提供者および障害により異なります。上流提供者は異なる法域で処理し、各自の規約、プライバシーポリシーおよび保存規則を適用します。リクエスト内容が一切記録されないことを保証しません。

お客様が Prompt、Completion、コード、ファイル、画像またはリクエスト例をサポート、チケットまたはフィードバック窓口へ自発的に提出した場合、当社はサポート、障害対応、リスク管理、紛争処理およびサービス改善に合理的に必要な範囲で保存・利用できます。処理する権利のない個人情報、営業秘密、パスワード、秘密鍵、完全な決済情報その他不要な機微情報を提出しないでください。

## 4. 情報の共有

個人情報を販売する目的で第三者に提供しません。サービス運営に必要な範囲で、次の受領者と共有する場合があります。

- **AI/API・モデル提供者**：モデル、推論、コード、ファイル、エージェントまたはツール呼出しの処理。
- **決済事業者**（Stripe を含む）：決済、サブスクリプション、本人確認・不正対策、返金、請求書および紛争処理。
- **クラウド・インフラ事業者**：ホスティング、通信、コンテンツ配信、データベース、キャッシュ、ログ、バックアップおよびセキュリティ。
- **ログイン、メール、リスク管理・サポート事業者**：OAuth ログイン、メール送信、Cloudflare Turnstile 等のボット対策、リスク識別および顧客支援。
- **専門家・政府機関**：法的義務、適法な手続、紛争対応、またはサービス・ユーザー・第三者の権利保護に合理的に必要な場合の弁護士、会計士、監査人、規制当局、裁判所・執行機関。
- **事業承継者**：合併、買収、資金調達、再編、資産譲渡等の取引における必要情報（合理的な秘密保持措置を講じます）。

第三者受領者は当社のサービス提供者である場合も、独立したデータ管理者となる場合もあります。Stripe および各 AI/API 提供者の独自の処理には各社のポリシーが適用されます。
